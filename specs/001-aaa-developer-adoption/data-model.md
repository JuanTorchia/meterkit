# Data Model: AAA Developer Adoption

## PublicPaymentReceipt (schema version 1)

Sanitized, stable evidence for a payment attempt.

| Field | Rules |
|---|---|
| `schemaVersion` | Literal `1` |
| `receiptId` | UUID generated by MeterKit |
| `productId` | Non-empty stable product identifier |
| `network` | Supported CAIP-2 Solana devnet identifier |
| `assetMint` | Valid Solana address |
| `amountAtomic` | Positive base-10 integer string |
| `recipient` | Valid Solana address |
| `payer` | Optional valid Solana address |
| `resource` | Normalized origin, explicit port, and pathname; no query secrets |
| `decision` | `accepted`, `rejected`, `unknown`, or `failed` |
| `settlement` | `not_started`, `pending`, `confirmed`, `finalized`, `unknown`, or `failed` |
| `signatureFingerprint` | Optional `sha256:` prefix plus 16 lowercase hex chars |
| `explorerUrl` | Optional official devnet URL; never logged by default |
| `policyDecisions` | Bounded ordered array of sanitized policy decisions |
| `createdAt` / `updatedAt` | UTC timestamps; update cannot precede creation |
| `reasonCode` | Stable uppercase code without raw provider payload |

### State transitions

```text
not_started -> pending -> confirmed -> finalized
                    |          |           |
                    +-------> unknown <----+
                    +-------> failed
```

`unknown` may recover to `confirmed`, `finalized`, or `failed`. `failed` requires
definitive evidence; infrastructure timeout alone cannot produce it.

## PaymentPolicyConfiguration

| Field | Rules |
|---|---|
| `id` | Lowercase stable identifier, max 64 characters |
| `mode` | `enforce` or `observe` |
| `onError` | Explicit `allow` or `deny` |
| `timeoutMs` | Integer 100-10000; default 2000 |
| `maxResponseBytes` | Integer 1024-65536; default 32768 |
| `maxAgeSeconds` | Integer 0-3600 |

## PolicyEvaluationInput

Contains normalized resource, network, mint, amount, recipient, and optional
payer/transaction. It MUST NOT contain signing material, authorization headers,
payment proofs, request bodies, or arbitrary query strings.

## PolicyDecision

| Field | Rules |
|---|---|
| `policyId` | Matches configuration |
| `provider` | Stable provider identifier |
| `outcome` | `allow`, `warn`, `deny`, or `error` |
| `reasonCodes` | Maximum 20 stable strings, 64 characters each |
| `confidence` | Optional number from 0 through 1 |
| `evaluatedAt` | UTC timestamp |
| `freshUntil` | Optional UTC timestamp |
| `onErrorApplied` | Present only for error outcomes |
| `metadata` | Optional bounded primitive-only map; denylist sensitive keys |

## CompatibilityRecord

Records MeterKit version, official dependency versions, runtime, network,
facilitator, surface, scenario result, evidence time, and exact source revision.
Records are generated, not hand-edited, and contain no credentials.

## ActivationAttempt

| Field | Rules |
|---|---|
| `attemptId` | Locally generated UUID |
| `participantAlias` | Optional participant-chosen alias; no email required |
| `consent` | Explicit evidence-sharing choice and timestamp |
| `startedAt` | UTC timestamp |
| `stages` | Ordered `install`, `challenge`, `settlement`, `receipt`, `replay`, `repeat_use` events |
| `assistance` | `none`, `documentation`, `verbal`, or `code_change` |
| `outcome` | `active`, `abandoned`, `blocked`, or `invalid` |
| `frictionCodes` | Bounded taxonomy, no free-form personal information |
| `evidence` | Sanitized receipt IDs and public URLs only with consent |

## Relationships

- One payment receipt has zero or more policy decisions.
- One activation attempt references zero or more public receipts.
- One compatibility record validates one release/surface/dependency combination.
- Policy configuration belongs to the SDK consumer, never a global hosted owner.
