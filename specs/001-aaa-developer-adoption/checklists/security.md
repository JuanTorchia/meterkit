# Security requirements quality

- [x] Trust boundaries name network, mint, amount, recipient and resource.
- [x] Replay, idempotency and concurrent persistence have acceptance criteria.
- [x] Secrets, signatures and personal data have explicit exclusion rules.
- [x] Third-party policy timeout, size, origin and failure semantics are testable.
- [x] Devnet-only scope and non-custodial invariants are explicit.
- [x] Finality unknown is distinguished from onchain failure.
