# MeterKit support

MeterKit is an early, devnet-only open-source project.

| Need                       | Channel                                                                                             |
| -------------------------- | --------------------------------------------------------------------------------------------------- |
| Reproducible bug           | [Bug report](https://github.com/JuanTorchia/meterkit/issues/new?template=bug-report.yml)            |
| Product or design proposal | [Feature proposal](https://github.com/JuanTorchia/meterkit/issues/new?template=feature-request.yml) |
| Usage question or idea     | [GitHub Discussions](https://github.com/JuanTorchia/meterkit/discussions)                           |
| External devnet pilot      | [Pilot start](https://github.com/JuanTorchia/meterkit/issues/new?template=pilot-start.yml)          |
| Security vulnerability     | [Private vulnerability report](https://github.com/JuanTorchia/meterkit/security/advisories/new)     |

Before requesting help, search existing issues, read the
[README](README.md), and run the public check:

```bash
pnpm pilot:check
```

Community support is best effort and has no SLA. Paid integration and dedicated
support may be offered separately; payment never changes the security disclosure
process or gives a customer authority over open-source governance.
