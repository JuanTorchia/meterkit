# Changelog

## [0.2.0] - 2026-08-11

- Add canonical `protect()` middleware, versioned public receipts and sanitized lifecycle events.
- Add maintained Next.js App Router and clean-package activation examples.
- Add generic bounded payment policies and removable Webacy Solana payer-risk adapter.
- Add consented pilot activation evidence, compatibility reporting and exact-commit AAA evidence tooling.

All notable MeterKit changes will be documented here.

The project uses [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
will follow semantic versioning after `1.0.0`.

### Added

- Open-source contribution, governance, support and security policies.
- Structured bug, feature, documentation and external-pilot issue forms.
- Pull request checklist and ownership rules.
- Tenant-scoped product identity with internal UUIDs and owner/slug routes.
- Standalone Express SDK quickstart and OIDC trusted-publishing workflow.
- Automated pull-request title policy and isolated major dependency upgrades.

### Changed

- Core GitHub Actions upgraded to v7 while retaining immutable SHA pins.
- Public demo language now distinguishes internal devnet evidence from external use.

### Fixed

- Complete canonical Apache-2.0 license text for repository and package detection.
- WCAG contrast, region semantics and keyboard access in public product pages.

## [0.1.0] - 2026-08-10

Initial public Core and SDK registry baseline with:

- non-custodial x402 USDC middleware for Solana;
- PostgreSQL receipts, idempotency and replay protection;
- Next.js provider dashboard and example paying client;
- paid Solana Project Scout MCP tool;
- bounded allowances, subscriptions and wallet-controlled revocation;
- reproducible CI, CodeQL, SBOM and container scanning.

Core and SDK `0.1.0` are published. They remain an immutable historical
baseline; the repository does not claim provenance for those artifacts.
