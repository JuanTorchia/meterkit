# Operaciones y resolución de problemas

Valida red, mint, monto, destinatario y recurso normalizado antes de firmar. Mantén el material de wallet fuera de logs y repositorios. Trata caídas de dependencias como estados desconocidos recuperables y reintenta con espera acotada.

El rollback nunca sobrescribe una versión npm. Consulta el [modelo de confianza](./trust) antes de operar un gateway alojado.
