# Ciclo de pago

Una llamada sin pago recibe HTTP 402 con red, mint, monto, destinatario y recurso exactos. El cliente firma solamente un alcance aceptable, reintenta y recibe el resultado protegido después de validar la liquidación.

Los recibos son durables y el replay se rechaza. Un RPC no disponible produce un estado desconocido, nunca un fallo onchain inventado. Consulta [operaciones](./operations) para la recuperación.
