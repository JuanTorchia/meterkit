# Comenzar con MeterKit

MeterKit agrega pagos USDC no custodiales a APIs y herramientas MCP. El proveedor recibe la liquidación directamente; MeterKit no conserva fondos ni claves privadas.

Instala el SDK público en un servicio existente, elige una [integración](./integrations) y comprende el [ciclo de pago](./concepts) antes de superar el desafío sin pagar.

```bash
pnpm add @usemeterkit/sdk@0.2.0 express
```

El inicializador todavía no es una release npm. Desde un commit exacto del
repositorio ejecuta `pnpm create:meterkit ../demo --surface express
--package-manager pnpm --yes`.
