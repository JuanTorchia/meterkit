# Referencia de compatibilidad

Core, SDK y el inicializador son los paquetes públicos primarios en 0.2.0. Los paquetes oficiales x402 avanzan como un conjunto coordinado detrás de pruebas de compatibilidad. Los majors de Solana Kit usados por x402 y Subscriptions permanecen aislados.

Consulta la [matriz de integraciones](./integrations) y `docs/compatibility.md` para los pins exactos.
