# Compatibility reference

Core and SDK are the primary public packages at 0.1.0. Official x402 packages move as a coordinated set behind compatibility tests. Solana Kit majors used by x402 and Subscriptions remain isolated rather than forced into one dependency context.

See the [integration matrix](./integrations) and repository `docs/compatibility.md` for exact pins.
