# Operations and troubleshooting

Validate network, mint, amount, recipient and normalized resource before signing. Keep wallet material outside logs and repositories. Treat dependency outages as recoverable unknown states and retry with bounded backoff.

Release rollback never overwrites an npm version. Consult the [trust model](./trust) before operating a hosted gateway.
