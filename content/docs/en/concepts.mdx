# Payment lifecycle

An unpaid call receives HTTP 402 and exact network, mint, amount, recipient and resource requirements. The client signs only an acceptable scope, retries, and receives the protected result after settlement validation.

Receipts are durable and replay is rejected. An unavailable RPC produces an unknown state, never a fabricated onchain failure. See [operations](./operations) for recovery.
