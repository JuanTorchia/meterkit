# Integration surfaces

Express is the recommended middleware path. Next route handlers and MCP tools are supported. Hono uses the official x402 adapter and remains experimental until its external pilot evidence matches Express.

All surfaces must preserve the same Solana devnet terms, receipt semantics and replay boundary. Review the [reference](./reference) before selecting versions.
