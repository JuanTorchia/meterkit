# Applicant checklist

These steps require the applicant’s identity, account or purchasing decision and
must not be delegated to the repository.

## Before uploading

- [ ] Confirm the GitHub repository is public and opens while logged out.
- [ ] Confirm no real `.env`, keypair, seed phrase or private key is tracked
      (`.env.example` is intentionally public and contains placeholders only).
- [ ] Open the devnet Explorer transaction in an incognito window.
- [ ] Export the six Markdown files in this folder to PDF only if the form
      preview does not render Markdown cleanly.
- [ ] Include `dashboard-desktop.png` and `dashboard-mobile.png`.
- [ ] Do not include `.local-wallets`, `.env` or database dumps.

## Drive folder

- [ ] Create `MeterKit — Agentic Engineering Grant — 2026-08-03`.
- [ ] Upload the contents of the generated grant pack.
- [ ] Put `01-APPLICATION-RESPONSE` first if Drive reorders files.
- [ ] Set access to **Anyone with the link — Viewer**.
- [ ] Test the folder URL in an incognito/private browser.

## Application form

- [ ] Use the title: `MeterKit — non-custodial USDC payments for APIs and AI agents`.
- [ ] Paste `01-APPLICATION-RESPONSE.md` as the principal response.
- [ ] Use the repository URL: <https://github.com/JuanTorchia/meterkit>.
- [ ] Add the Drive folder URL.
- [ ] Add the devnet Explorer transaction under proof of work.
- [ ] Enter the applicant’s legal name, email, profile and public wallet manually.
- [ ] Complete KYC only through the official Superteam flow.

## Financial caution

- [ ] Do not purchase a subscription solely on an assumption of approval.
- [ ] After approval, confirm which coding plans and receipt dates are eligible.
- [ ] Retain invoices/receipts totaling USD 200 for the second tranche.
- [ ] Do not spend mainnet funds or deploy to mainnet for this application.

## After submission

- [ ] Save the confirmation page and submission timestamp.
- [ ] Record any reviewer questions verbatim.
- [ ] Update claims only after new evidence exists.
- [ ] Preserve the submitted Drive version so the evidence does not change
      silently during review.
