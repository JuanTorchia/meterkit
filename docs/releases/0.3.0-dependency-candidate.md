# 0.3.0 dependency candidate

This unreleased candidate coordinates x402 2.22.0 across every maintained and
generated payment surface. MeterKit APIs are unchanged, but consumers rebuilding
from source resolve the newer x402 implementation.

No application migration is required. Regenerate projects or reinstall with
the lockfile; do not mix x402 2.21 and 2.22 adapters in one generated surface.
The Solana Kit 5 and Subscriptions Kit 6 cohorts remain deliberately separate.

Rollback is cohort-atomic: restore every x402 manifest and compatibility fixture
to 2.21.0, restore Next to 16.2.12 where applicable, restore the previous
lockfile, then rerun package, quickstart and payment regression gates. CodeQL
init/analyze must likewise be rolled back together.
