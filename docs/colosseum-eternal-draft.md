# Borrador — Colosseum Eternal

## One-liner

MeterKit lets any API or MCP developer charge AI agents USDC on Solana with three lines of middleware.

## Problem

Machine customers cannot reliably navigate account creation, cards, API keys and invoices; payment processor availability is uneven globally.

## Product

x402 v2 payment gate, direct USDC settlement, receipts, dashboard, native subscriptions and bounded allowances. Solana Project Scout demonstrates a paid, useful MCP tool with factual sourced output.

## Why Solana / why now

Official x402 SVM support and newly released Subscriptions & Allowances make per-call and recurring machine commerce composable without MeterKit custody.

## Four-week sprint

- Week 1: exact devnet payment and security suite.
- Week 2: dashboard, indexer, example client.
- Week 3: MCP Scout, subscriptions, allowance/revoke.
- Week 4: five pilots, hosted preview, demo and measurement.

## Business model

Open-source core; hosted analytics; $49 Pro; paid integrations; transparent optional ≤1% fee only if user-signed and non-custodial.

## Evidence to attach

GitHub, live devnet URL, Explorer receipt, 90-second demo, test report, five pilot quotes. Do not claim pilots or revenue until obtained.
