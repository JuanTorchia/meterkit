# MeterKit — pitch deck

---

## 1. Cobros nativos para software nativo de agentes

USDC payments for the agentic web.

---

## 2. El problema

Vender una API exige cuentas, tarjetas, API keys y facturación. Los agentes no rellenan formularios y muchos builders de LatAm no acceden a los mismos rails.

---

## 3. La solución

Conecta wallet → crea producto → fija precio → protege endpoint. x402 negocia el pago; Solana liquida USDC directamente; MeterKit entrega y registra el recibo.

---

## 4. Demo

Premium Weather API cuesta 0,01 USDC. Primera llamada: 402. El cliente firma y reintenta. Respuesta: datos + recibo + Explorer. Replay: rechazado.

---

## 5. Por qué ahora

x402 v2 soporta Solana; Subscriptions & Allowances ofrece delegaciones limitadas y planes; MCP estandariza herramientas para agentes. Las piezas existen, falta producto.

---

## 6. Mercado inicial

APIs, servidores MCP, datos para agentes, generación/análisis/automatización permitida y micro-SaaS globales. Beachhead: builders Solana y LatAm.

---

## 7. Producto

SDK Apache-2.0, gateway, dashboard, recibos, subscription mensual, allowances con límite/vencimiento y Solana Project Scout.

---

## 8. Negocio

OSS gratuito; hosted Starter; Pro $49/mes; integración desde $1.500; enterprise. Hasta 1% sólo como reparto explícito, firmado y no custodial.

---

## 9. Go-to-market y métricas

3–5 design partners → caso público → templates MCP/API → Superteam/Colosseum. Norte: volumen liquidado; primeros hitos: 10 pagos devnet, 5 instalaciones, 1 integración pagada.

---

## 10. Solicitud

Financiar cuatro semanas para endurecer settlement, completar subscriptions, incorporar pilotos y desplegar testnet. Sin token, trading, custodia ni promesas financieras.
