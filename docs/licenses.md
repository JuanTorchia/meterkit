# Dependency and image licensing

Reviewed on **2026-08-17** for the production dependency graph and candidate
updates.

- MeterKit source is Apache-2.0.
- Direct runtime dependencies use permissive licenses compatible with this
  distribution.
- The coordinated x402 2.22.0 packages are Apache-2.0. Next.js 16.3.1,
  React 19.2.8 and express-rate-limit 8.6.2 are MIT. The changed development
  tools `tsx` 4.23.12 and `typescript-eslint` 8.67.0 are MIT.
- The Next.js image pipeline can include the LGPL-3.0 `libvips` binary through
  `sharp`. MeterKit does not modify that binary; corresponding upstream source
  and license notices remain available from the libvips/sharp projects.
- `caniuse-lite` carries CC-BY-4.0 metadata used during web builds.
- A CycloneDX workspace SBOM (691 components) was generated on the designated
  server for the dependency candidate; runtime image SPDX SBOMs remain CI
  release artifacts bound to the exact commit.

Before publishing a binary release, retain dependency license files and archive
the two SPDX JSON artifacts generated by CI. This inventory is operational
documentation, not legal advice.
