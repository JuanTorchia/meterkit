# Webacy Startup Accelerator — draft

Status: candidate integration; not submitted from this repository. Consulted
2026-08-10 from the [official Superteam listing](https://superteam.fun/earn/grants/startup-accelerator-grant)
and [Webacy documentation](https://docs.webacy.com/introduction).

MeterKit adds an optional payer-risk policy to its non-custodial Solana x402
middleware. A public address can be screened before an autonomous agent spends
USDC, with bounded timeouts, explicit fail mode, minimized data and auditable
reason codes. The adapter is removable and does not place Webacy in settlement.

Requested accelerator outcome: validate the Solana address endpoint, thresholds
and rate limits; publish the adapter; onboard three independent integrations;
and co-author a factual technical case study only with consented evidence.

The listing advertises up to 10,000 in DD.xyz API credits, a three-month
integration window and possible co-marketing. Treat this as in-kind support, not
cash or guaranteed distribution. No customer, pilot or revenue is claimed.
